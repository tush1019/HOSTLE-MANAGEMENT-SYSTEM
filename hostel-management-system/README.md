# HostelHub

HostelHub is a full-stack hostel management system with Admin and Student panels, staff management, and private admin-student chat.

## Quick Start
See `docs/DOCUMENTATION.md` for full setup, environment variables, deployment, and API details.

## Tech Stack
React + TypeScript + Vite, Node.js + Express, MySQL/SQLite.

## Features
- Admin and Student role-based panels
- Rooms, students, fees, complaints, mess, facilities, notices
- Staff/faculty management
- Private chat/messaging with unread counts
- OTP-based signup/login

## Run Locally
Backend:
```bash
cd backend
npm install
node server.js
```

Frontend:
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
